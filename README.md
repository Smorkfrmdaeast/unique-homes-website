# UNIQUE HOMES - Premium Fragrance

A modern React & TypeScript web application for UNIQUE HOMES, showcasing luxury perfumes, home diffusers, body sprays, and air fresheners.

## Features

- **Brand Hero**: Signature luxury typography, gold accents, and direct call-to-actions.
- **Product Catalog**: Complete collection including Luxury Perfume, Home Diffuser, Body Spray, and signature scents with interactive category filtering and scent note breakdowns.
- **WhatsApp Integration**: Direct ordering integration via pre-filled WhatsApp links for instant inquiries and checkout.
- **Why Choose Us**: Highlighting authenticity, longevity, fast delivery, affordable luxury, and customer satisfaction.
- **Customer Reviews**: Testimonials and ratings from verified buyers.
- **Floating Contact**: Seamless floating WhatsApp button for one-tap concierge support.
- **Responsive Navigation**: Sticky navbar with scroll elevation and mobile navigation drawer.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Icons**: Lucide React
- **Styling**: Custom CSS matching the brand's signature black, white, and gold (`#D4AF37`) palette

## Development

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
